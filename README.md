# Customer Finder

帮技术创始人找到产品的真实付费客户渠道。

## 功能

- 🎯 自动分析潜在客户画像
- 🔍 爬取 Reddit/ProductHunt/IndieHackers 相关讨论
- 📊 输出带优先级的客户获取渠道清单
- 📧 生成联系方式模板

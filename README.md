# Customer Finder - 自动客户发现工具

自动发现和验证目标客户的 CLI 工具，帮助技术创始人和独立开发者找到真正会付钱的客户。

## 核心功能

- 🎯 根据产品描述自动生成目标客户画像
- 🔍 从 Reddit/HackerNews 抓取相关讨论和痛点
- 📊 输出潜在客户列表（含联系方式和痛点匹配度）
- ✉️ 生成个性化冷邮件模板

## 工作流程

1. **生成客户画像**: 使用 GPT-4 分析产品描述，生成目标客户特征
2. **搜索讨论**: 在 Reddit (r/SaaS, r/startups 等) 和 HackerNews 搜索相关讨论
3. **分析匹配度**: 使用 AI 分析讨论内容，计算痛点匹配度
4. **生成邮件**: 为高匹配度客户生成个性化冷邮件模板

## 最佳实践

1. **产品描述要具体**: 包含目标用户、核心功能、解决的问题
2. **定期运行**: 每周运行一次，持续发现新客户
3. **手动筛选**: AI 匹配度仅供参考，需人工验证
4. **个性化邮件**: 使用生成的模板作为基础，添加个人化内容
5. **追踪效果**: 记录联系结果，优化搜索关键词

## 风险点与限制

- **API 限制**: Reddit/HackerNews API 有速率限制
- **准确性**: AI 分析可能有误判，需人工复核
- **联系方式**: 工具不直接提供邮箱，需手动查找
- **成本**: OpenAI API 调用会产生费用（约 $0.01-0.05/次查询）

## 故障排查

### 错误: 未设置 OPENAI_API_KEY
确保 `.env` 文件存在且包含有效的 API Key

### Reddit 搜索失败
检查 Reddit API 凭证是否正确，或尝试减少搜索频率

### 没有找到潜在客户
- 调整产品描述，使其更具体
- 增加 `--limit` 参数值
- 检查搜索关键词是否合适
